# 采访提纲（草案 v1，待审）

这是**草案**，不是已定稿的设计，也还没写进代码。基线是 0.8.1（分支 `main-081`）现在的采访流程
（`demo/src/core/script.ts` 的四块脚本、`demo/src/core/prompts.ts` 的提问与整理提示词）。

## 0. 这一稿相对现在改了什么

| | 现在（0.8.1） | 这一稿 |
|---|---|---|
| 区块 | 事情 / 人际 / 物品 / 状态（4 块） | 事情 / 人际 / **物与钱** / **状态（含成长）**（仍是 4 块） |
| 题目性质 | 每块 4 个主问题，一律要问 | 每块分三类：**必问**（保证覆盖）/ **追问池**（说到相关处才追）/ **聊开才问**（不占必问名额） |
| 决策复盘 | 没有 | 事情里加一道必问：「这周你做的最关键的一个判断是什么」 |
| 认知与成长 | 没有（只有「状态」里一句「还有什么我没问到、但你想说的」） | 并进「状态」，成为其中一个必问：「这周有什么输入？学到的一条能用的？」 |
| 钱 | 散在「物品」里，范围没定义 | 范围写进 hint：实物 / 花销与订阅 / 该维护该续费的事 |
| 上周对账 | **完全没有**（采访不带上周记录） | 开场先对账：把上周的「下周重点 + 要跟进的人」带进来问一遍 |

## 1. 全局规则（沿用现在的，不改）

- 一次只问一件事，不把几个问题堆在一句里。
- 每个主问题最多追问 3 次，到顶就换下一题。
- 不评价、不说教、不替对方下结论；用对方自己的说法，不改写成书面语。
- 主问题问完之后，用户还想说就自由聊，不再受追问上限约束。
- 题目由脚本保证覆盖，模型只负责「怎么问」。

## 2. 四块提纲

### 事情（这周做了什么）

**必问**
1. 这周主要忙了些什么？
2. 有没有本来打算做、结果没做成的事？卡在哪一步了？
3. **这周你做的最关键的一个判断是什么？当时依据什么，现在回看还成立吗？** ← 新增（决策复盘）
4. 有没有突然插进来、打乱你计划的事？

**追问池**（说到才追，不硬问）
- 这件事哪一部分最花时间？/ 后来结果怎么样了？/ 当时你是怎么处理的？
- 时间大致是怎么分配的？哪块投入产出比最低？ ← 从「必问」降下来：硬问必然得到敷衍的答案

**聊开才问**
- 有没有本该做、但一直没做的事？为什么没做？

**这块要捞出来的东西**：做了什么 + 卡点 + **一个判断及其依据**（判断是整理那一步「主线要有取舍和判断」的原料，现在脚本根本不问）。

### 人际（和谁有关，卡在哪里）

**必问**
1. 这周跟谁打交道最多？
2. 有没有想联系、但一直没联系的人？为什么一直没联系？
3. 有没有谁帮了你，或者你帮了谁的忙？
4. 这周有没有哪次互动，让你事后觉得不太舒服？当时你怎么处理的？ ← 中性化改写（原「边界被侵犯 / 自己越界」审判感太强，和人设里「不评价」冲突）

**追问池**
- 有没有哪件事卡在对方那里？/ 后来你们是怎么说的？/ 这个人最近让你印象最深的是什么？
- 有没有需要主动开口求助、或者该谢一声的人？ ← 原题说它「很多人漏、收益很高」，那就别硬问，放追问池更稳

**聊开才问**
- 有没有该维护、但一直没维护的关系（家人、老客户、关键同事）？ ← 从「必问」降下来：这题自带道德压力，问早了容易防御

### 物与钱（买了什么、花了什么、该维护什么）

**先定义范围**（写进这一块的 hint，否则这栏永远只有「买了点什么」）：
实物（工具、设备、家居）/ 花销与订阅（续费、会员、数字资产）/ 该维护的事（备份、保修到期、体检、清理）。

**必问**
1. 这周买了什么、或者添置了什么？用上了吗？
2. 这周有没有买了、但没用上的？当时为什么买？ ← 消费观最好的素材
3. 有没有该续费、该维护、该修的，一直拖着没做的？

**追问池**
- 有没有处理掉、退掉、或者卖掉的东西？
- 现在回头看，这笔花得值不值？/ 买它是因为什么？

**聊开才问**
- 你现在的环境（房间、桌面、手机、电脑）是帮忙还是添堵？有没有可以清掉的？

### 状态（这周过得怎么样 + 学到了什么）

「成长」按你的意见并在这一栏，所以它是四个必问，各对一项：身体 / 情绪 / 精力 / 成长。

**必问**
1. 这周整体感觉怎么样，累不累？（情绪基调）
2. 睡眠、精神头、身体状态怎么样？（身体）
3. 这周有没有哪个瞬间让你觉得挺舒服、挺值的？（精力落到具体事上）
4. **这周有什么输入吗 —— 看的书、听的课、跟人的对话？学到的一条能马上用的？** ← 新增（成长）

**追问池**
- 主要是被什么影响的？/ 这种状态持续多久了？
- 这周有没有哪件事改变了你的看法？ ← 这条既是成长，也是决策复盘的原料，模型碰到「判断 / 看法」话题时优先追
- 高峰时段你在做什么？被什么打断最多？

**聊开才问**
- 那你打算怎么调整？

## 3. 开场：先对个账（新增，有三件事要你拍板）

采访开始前，把上一周记录里的「下周重点 3 条」和「要跟进的人 2 个」喂给模型，
第 0 题变成：「上周你定的是这三件事 —— A / B / C，还有要跟进的 X、Y。实际落到了哪儿？」

要定的事：

1. **对账要不要单独占一栏输出？** 我建议**要**：给现在七栏的结果加**第八栏「上周对账」**，
   每条带「做到了 / 只做了一部分 / 没提到」三档。不然这部分只活在聊天记录里，
   总览页看不到，下周也接不上 —— 那就白问了。
2. **上周没有记录时怎么办？** 我建议直接跳过对账、按老样子开问。
3. **用户答「没做 / 忘了」算不算未办？** 我建议算在「上周对账」里，别混进 `pending` ——
   「上周没做到」和「这周还没做」不是一回事。

技术上要加的东西（说清成本）：**采访与整理都要带上周的内容**。0.9.0 已经写过一遍
（`previousWeekContext`：只取紧邻上一周的计划与问题标签），思路和代码可以搬回来。

## 4. 上限（避免把人问跑）

- 必问：4 块 × 3~4 题 ≈ **14 题**。
- 每题最多追问 3 次 → 理论上限约 40 轮，**实际目标 20~30 轮、15 分钟以内**。
- 「聊开才问」的题不占必问名额，只有用户主动提到相关线索时才追。

## 5. 还没定 / 我的保留意见

- **打分不做**：睡眠、精力打 1~5 分只有在能看趋势时才值钱。现在没有趋势也没有图表，
  分数躺进聊天记录里活不过一周。除非以后做趋势，否则用「高峰在做什么」这种具体问法代替。
- **状态块会不会太长**：4 个必问（身体 / 情绪 / 精力 / 成长）是四栏里最多的。
  备选是把「哪个瞬间挺值」并入情绪，只留 3 个必问 —— 等你审完再定。
- **区块名**：`物品` → `物与钱`；`状态` 保持（成长在里面，hint 改成「这周过得怎么样、学到了什么」）。
- 题目措辞还可以再压短，让模型更容易「顺着话说」而不是「念题目」。
