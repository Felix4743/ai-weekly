（`demo/src/core/script.ts` 的题库、`demo/src/core/interview.ts` 的换块状态机、`demo/src/core/prompts.ts` 的提问与整理提示词）。

## 0. 这一稿相对 0.8.1 定下来的

| | 现在（0.8.1） | 这一稿 |
|---|---|---|
| 顺序 | 事情 → 人际 → 物品 → 状态 | **状态 → 定深度 → 对账 → 事情 → 人际 → 物与钱** |
| 题目性质 | 每块 4 题，一律要问；题目即脚本 | 题目**仅供参考**，模型按回答决定怎么问、问多深 |
| 每轮说话量 | 提示词硬性「只输出一句话、≤120 字」 | **一句可以多问几个问题，但不能太多** |
| 追问 | 每题最多 3 次 | 问**到复盘的效果**为止，再换下一题 |
| 语气 | 不评价不说教 | 采访阶段中立收集；**最后复盘可以评价，对事不对人** |
| 决策复盘 | 没有 | 事情里加一道必问：最关键的一个判断 + 当时依据 |
| 认知与成长 | 没有 | 并进「状态」的第四项（心智） |
| 钱 | 散在「物品」，范围没定义 | 改名**物与钱**，范围写进 hint，加「这周的支出情况」 |
| 状态 | 4 个问句、结果里没有位置 | **四个子项（身体/情绪/精力·专注/心智）并打分，新增一张「状态」卡承载** |
| 时长 | 固定四块走完 | **看用户状态定档**：深度约 20 分钟 / 中度 / 快速约 5 分钟 |
| 上周对账 | 完全没有 | 定档之后先对账；**不新增栏**，没做到/做一半的并进已有的「未办」卡 |

## 1. 全局规则（你改的，照办）

- 一句可以多问几个问题，但不能太多。
- 每个主问题可以问到复盘的效果，然后再问下一个。
- 不说教、不替对方下结论；保持中立收集，最后复盘可以评价，对事不对人。
- 主问题问完之后，用户还想说就自由聊，不再受追问上限约束。也要有关的加入复盘。
- 题目仅供参考，模型根据用户回答思考「怎么问」。

|---|---|---|

## 2. 采访顺序

```
① 状态（四个子项，最轻最软，先来）
② 定深度：问一句「我们深度/中度/快速复盘，可以吗？」
③ 对账（只有上周有记录时才问）：上周定的三条 + 要跟进的人，实际落到哪儿
④ 事情 → 人际 → 物与钱（按档位决定问多少、追多深）
⑤ 收尾：补漏一句「还有什么我没问到、但你想说的？」
```

为什么状态放最前：它是唯一一个**不需要回忆、不需要诚实面对没做到的事**的区块，最容易开口；
而且它的答案决定了后面能问多深 —— 用户今天累，你硬上 20 分钟，后半程全是敷衍。

## 3. 四块提纲

### 状态（第一块，四个子项）

**必问**（一个子项一句，不要一句话里连问四个）
1. **身体**：这周睡眠、运动、吃饭怎么样？（各打 1~5 分）
2. **情绪**：整体基调怎么样？这周最消耗情绪的一件事是什么？
3. **精力/专注**：高峰时段在做什么？被什么打断最多？
4. **心智（成长）**：这周有什么输入（书、课、对话）？学到的一条能马上用的是什么？

**追问池**
- 主要是被什么影响的？这种状态持续多久了？
- 这周有没有哪件事改变了你的看法？（既是成长，也是决策复盘的原料）
- 那你打算怎么调整？

**这块要捞出来的东西**：四项各一句 + 分数。分数是这一块唯一的结构化产出。

### 事情（这周做了什么）

**必问**
1. 这周主要忙了些什么？
2. 有没有本来打算做、结果没做成的事？卡在哪一步了？
3. 这周你做的最关键的一个判断是什么？当时依据什么，现在回看还成立吗？
4. 有没有突然插进来、打乱你计划的事？
5. 这周有没有做新鲜事？

**追问池**（说到才追，不硬问）
- 这件事哪一部分最花时间？/ 后来结果怎么样了？/ 当时你是怎么处理的？
- 时间大致是怎么分配的？哪块投入产出比最低？

**这个也要问**
- 有没有应该做、但一直没做的事？为什么没做？

**这块要捞出来的东西**：做了什么 + 卡点 + 一个判断及其依据。

### 人际（和谁有关，卡在哪里）

**必问**
1. 这周跟谁打交道最多？
2. 有没有想联系、但一直没联系的人？有什么原因吗？
3. 有没有一次沟通本可以更好？下次怎么开口？
4. 有没有边界被侵犯、或者自己越界的情况？当时怎么处理的？

（题面按你的话留。配套规则写清楚：**追问时不许评判用户**，只把当时的情形问细 —— 语气的事靠规则管，不靠改题目措辞。）

**追问池**
- 有没有哪件事卡在对方那里？/ 后来你们是怎么说的？/ 这个人最近让你印象最深的是什么？
- 有没有需要主动开口求助、或者该谢一声的人？

**聊开才问**
- 有没有该维护、但一直没维护的关系（家人、老客户、关键同事）？

### 物与钱（买了什么、花了什么、该维护什么）

**先定义范围**（写进这一块的 hint，否则这栏永远只有「买了点什么」）：
实物（工具、设备、家居）/ 花销与订阅（续费、会员、数字资产）/ 该维护的事（备份、保修到期、体检、清理）。

**必问**
1. 这周买了什么、或者添置了什么？用上了吗？
2. 这周有没有买了、但没用上的？当时为什么买？
3. 有没有该续费、该维护、该修的，一直拖着没做的？
4. 这周的支出情况？

**追问池**
- 有没有处理掉、退掉、或者卖掉的东西？
- 现在回头看，这笔花得值不值？买它是因为什么？

## 4. 对账（定档之后问，不加栏）

**问法**（只在上一周有记录时）：

> 上周你定的是这三件事 —— A / B / C，还有要跟进的 X、Y。实际落到了哪儿？

**结果落在哪**：

- 没做到、只做了一半的 → 写进**已有的「未办」卡**，文字里带上「上周说好的」字样
  （例：`上周说好的把报价发出去 —— 只发了初稿`）。不新增栏。
- 做到了的 → 不用单独记，它本来就会出现在「事情」里。
- 上一周没有记录 → 跳过对账，直接进事情块。
- 不要新增「上周对账」卡：结果页已经有 6 张卡，再加就真的太多了。

**技术上要加的**：采访与整理都要带上周内容（上周的「下周重点 + 要跟进的人」）。
0.9.0 写过一遍（`previousWeekContext`：只取紧邻上一周），思路和代码可以搬回来。

## 5. 结果长什么样

数据从七栏变**八栏**（多一个 `state`），结果页从 6 张卡变 **7 张卡**：

| 卡 | 数据栏 | 变化 |
|---|---|---|
| 事情 | `events` | 不变 |
| 人际 | `people` | 不变 |
| 物品 | `things` | 不变 |
| 未办 | `pending` | **新增承载「上周说好却没做到」的那一条** |
| 本周主线 | `highlights` | 不变（整理规则里「评价对事不对人」写在这） |
| 下周计划 | `nextFocus` + `nextFollowUps` | 不变（也是下周对账的输入） |
| **状态** | **`state`** | **新增**：身体 / 情绪 / 精力 / 心智 各一行，各带一个 1~5 分 |

## 6. 三档深度

问完状态，补一句确认（原话照你的）：

- 状态好 → 「我们深度复盘，可以吗」→ 约 **20 分钟**：每块必问全问 + 追问池，鼓励多说
- 状态一般 → 「我们中度复盘，可以吗」→ 约 **12 分钟**：每块必问，追问点到为止
- 状态差 / 时间紧 → 「我们快速复盘，可以吗」→ 约 **5 分钟**：每块只抓 1~2 个关键题，不追

用户改口（「今天算了，快点」）要能随时降档；聊开了也可以升档。

## 7. 我的三处保留意见（建议，不是否决）

- **「题目仅供参考」要配一条明确的换块判据**：不给判据的话，模型容易一直待在状态块里追问，
  四块走不完。我打算在提示词里写死「这一块的关键点都拿到了就换下一块，最多追到效果出现为止」。
- **分数现在只是卡里的一行字**：它要等以后做趋势页才真正值钱。哪个月卡片太挤，第一个可以砍的就是分数。
- **状态的四个子项建议一子项一问**：一句话里连问四个，用户只会答最后一个。
