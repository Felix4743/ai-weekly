# AI 周报

> 周末坐下来跟 AI 聊几分钟，得到一份属于自己的这一周的总结和下周计划。

对着空输入框写周报，大多数人写不出三行。所以这个工具换了个方向：**它来采访你** ——
一个问题一个问题地问，追着你的原话往下挖，最后归纳成八栏，每一条你都能改。

Electron 桌面应用，没有后端。你的 API Key 与所有周归档都只存在本机
（`%APPDATA%\ai-weekly\`）。

## 一次采访长什么样

1. **先打分** —— 这周心情 / 睡眠 / 运动 / 饮食，各点 0–5 颗星，下面一行备注。
   点第 N 颗就是 N 分，再点同一颗取消（取消等于没打分，存档里不写这一项）
2. **选深度** —— 深度复盘约 20 分钟 / 中度约 12 / 快速约 5；同一个话题最多连着追 5 / 2 / 1 次，
   到顶就换个方向。聊到一半还能改
3. **聊这几块** —— 状态追问（只聊你打了 2 星及以下的项，一项都不低就整步跳过）→
   上周对账（上周没留过记录就跳过）→ 事情 → 人际 → 物品与支出 → 成长。
   每一块只声明 3~4 个**要点**（「聊完这一块该知道哪几样」），**先聊哪个、聊几轮、往哪儿追由模型定**；
   收尾时它报一次覆盖（`[换块] 覆盖:1,3`），还差着的会在输入框上方提示你一句，补不补你决定。
   没感觉的要点可以点「这题跳过」
4. **生成结果** —— 本周主线 / 下周计划 / 事情 / 人际 / 物品与支出 / 未办 / 状态 / 成长，
   逐条可编辑、可删除、可新增；「重新整理」可以补一句话让它重写主线与计划
5. **归档** —— 按周存（键是那一周的周一），总览页有日历；一周里聊第二次会接着上次补，
   把新内容并进同一份

## 几个设计取舍（也许比功能本身有意思）

- **行首标记协议**：模型每轮的第一行只写 `[追问]` / `[换题]` / `[换块]` 三个标记之一。
  不用 JSON，因为 JSON 没法边收边显示 —— 一上流式就会看到半截花括号
- **状态机管要点覆盖，模型管怎么聊**：覆盖率、追问上限、防打转都是纯函数，
  **不连 AI 就能完整单测**（这也是这个仓库测试特别多的原因）
- **「聊到就算」，块内没有题序**：每块只给要点、不给一道一道的题目，治的是「问法像念表」
- **先接话再问**：协议要求每轮先说一句接住对方的话再往下问。早期版本写的是
  「不要前缀解释」，那条把「接话」整个掐死了，人设再活泛也只剩一层皮
- **跨栏上下文**：整场记录都给模型，前面几栏标成「只作背景」—— 它才接得上你上一栏提过的人和事
- **分数只由界面产生**：模型一个字都碰不到；生成结果与「重新整理」两步，都会拿界面上的
  真实点击覆盖掉它可能编出来的分数

## 跑起来

```
cd demo
npm install
npm run dev            # 渲染层开发服务器（在浏览器里看界面）
npm run electron:dev   # 真正的桌面窗口
```

第一次打开先到「设置」页填 API Key —— 只用 OpenAI 兼容接口，默认指向
`https://api.deepseek.com/v1`。**不填 Key 也能点进采访页**，那时候走的是演示用的假 AI
（本地拼答案、不联网），界面流程一样能走完。

打包成 Windows 安装包：`npm run dist`（产物在 `demo/release/`）。

## 测试与验证

```
npm run typecheck
npm test                  # 691 个用例 / 35 个文件，一个都不依赖网络
npm run smoke             # 真起一次窗口，看它能不能起来
npm run try:model         # 拿真 Key 跑完一整场采访（要联网、会花钱，单独一份配置）
```

界面层有几件事单测管不到（跳过之后屏幕有没有往下走、流式期间按钮的禁用态、
结果页的区块顺序），另外准备了几个真实界面验证脚本：`verify:skip`、`verify:result`、
`verify:installed`，以及量整场内存的 `measure:memory` / `measure:memory:walk`。

## 目录

```
demo/    应用本体
         src/core/     纯函数：采访状态机、提示词、归档、结果归纳（不碰 React / 网络 / 浏览器 API）
         src/ui/       React 界面
         src/host/     宿主能力（文件读写、LLM 转发）—— 不许 import electron
         electron/     只做接线
         live/         真模型试跑台
         scripts/      打包前后的检查与界面验证
docs/    产品设计文档 / 技术方案（含每一处取舍的由来与实测数据）
mvp/     版本史与关键决策：每一版做了什么、为什么
```

分层由 `demo/src/core/layering.test.ts` 守着：`core` 不许碰 React 与网络，`host` 不许 import electron。
